# 예지보전이란?
<span style='background-color:yellow'>
기계 설비의 상태를 실시간으로 모니터링하고 기계의 센서 데이터를 분석해 예고 없이 발생하는 고장을 사전에 예측하고 대비하는 유지보수 방식
</span>

설비 유지보수에서 고장에 대응하는 방식은 크게 네가지로 분류된다.
#### **1. 사후보전(reactive)**
이 중 가장 원시적인 방법은 "사후보전(reactive)"이다. 사후보전은 고장나면 즉각 가동을 중지하는 전략인데, 반도체 공정처럼 장비 하나가 멈추면 라인 전체가 영향받는 곳에서는 손해 비용이 매우 크다.
#### **2. 예방보전(preventive)**
"이 부품은 3개월마다 교체"처럼 정해진 주기로 미리 교체하고 점검하는 방식이다. 고장을 줄이긴 하지만, 멀쩡한 제품도 주기가 됐다는 이유로 교체되면 낭비가 발생하고, 반대로 주기보다 빨리 망가지는 경우도 잡을 수 없다. 
#### **3. 예지보전(predictive Maintenance,PdM)**
업계에서 흔히 PHM이라고 부르는 영역이다. 장비에서 나오는 센서 데이터를 실시간으로 관찰해서, 고장이 나기 전에 미리 이상 징후를 포착하고 "이 장비는 앞으로 몇 시간 후에 고장날 것 같다"를 예측하는 방식이다. 고장까지 남은 시간을 **RUL(Remaining Useful Life)** 또는 **TTF(Time-To-Failure)** 라고 부른다. 즉, 예지보전의 최종 목표는 RUL(잔존유효수명)을 예측하는 것이다.

해당 데이터의 경우 하나의 engine id당 가장 마지막에 찍힌 cycle이 고장시점이다. 예를 들어 engine id = 1의 경우 cycle 수가 1~100까지 데이터로 찍혀있다면 고장 시점이 100이다. 따라서 1번 엔진의 cycle 1회 시점에서 RUL은 99이다. 

#### **4. 처방적 유지보수(prescriptive)**
가장 진화한 형태로, 예측에서 그치지 않고 "그럼 언제 정비 인력을 투입하고 어떤 부품을 준비할 것인가"까지 최적화하는 단계이다. 

<span style='color:red'>
📌 현 프로젝트에서는 예지보전 단계까지가 목표이며, 대시보드로 그 결과를 모니터링 할 수 있도록 보여주는 것까지 포함한다.
</span>

### 예지 보전이 어려운 이유
1. 고장 데이터가 절대적으로 작다. -> 일반적인 분류 문제와는 다른 접근이 필요하다. 
<br>

2. **정확도** 만으로는 의미없다. -> 오경보가 너무 잦으면 현장에서 일일히 확인할 수 없고, 너무 늦게 감지되면 대응할 시간이 없다. -> 따라서 오경보율과 리드타임(얼마나 일찍 감지하는가)의 trade off가 핵심 평가지표가 된다.
