# HistGradientBoosting (히스토그램 기반 그래디언트 부스팅)

> 앙상블 학습 방법 중 하나이다.  여러 개의 결정 트리를 조합하여 예측 모델을 구축하는 알고리즘이다. 
> 행이 많고 열이 중간 정도인 대규모 table형 데이터에서, 특징과 정답이 비선형이거나 특징끼리 상호작용이 있을 때 적합하며, 기존 gradientboosting보다 빠르고 나은 성능이 필요할 떄 주로 사용한다.

### 개념
- 작은 결정 트리를 **순서대로** 쌓는 방법이다. 
- 히스토그램 기반이다. 학습 전에 각 특징을 최대 255구간으로 묶어두고, 분기점을 모든 값이 아닌 구간의 경계에서 찾는 방법이다. 따라서 대용량 데이터에서 빠른 속도로 이점을 얻을 수 있다.
- 결측값과 범주형 변수들을 자동으로 처리한다.


### 주요 설정값
|설정|sklearn 기본값|의미|
|---|------------|---|
|max_iter|100|쌓을 트리 개수|
|learning_rate|0.1|트리 하나가 반영되는 비율. 작을수록 천천히 학습하며 더 많은 트리가 필요|
|max_leaf_nodes|31|트리 하나의 최대 잎 수. 이득이 큰 잎부터 쪼갬|
|min_samples_leaf|20|잎 하나가 가져야 할 최소 샘플 수. 너무 작은 그룹을 막음|
|12_regularization|0|L2규제.값을 0쪽으로 줄여서 과적합을 막음|
|max_bins|255|구간개수|
|early_stopping|'auto'|샘플이 10,000개를 넘으면 켜짐. 검증 점수가 더 안좋아지면 멈춤|

### 해당 모델 선택 이유
- 가장 단순한 것부터 단계적으로 비교함. 평균예측-선형회귀-히스트그래디언트부스팅. RMSE값을 계산했을 때 히스트그래디언트부스팀 모델이 가장 작은 값을 가짐
- 해당 프로젝트의 메인 과제는 모니터링 시스템이였기 때문에, 적은 비용으로 가장 큰 이득을 낼 수 있는 모델을 선택함 : 선형회귀는 열화곡선을 따라가지 못하기 때문에 곡선을 따라갈 수 있는 모델을 골라야하는데 튜닝이 간단하고 cpu없이 lightGBM,XGBoost와 유사한 효율을 낼 수 있다는 점에서 선택함.
- 열화곡선을 따라갈 수 있는 다양한 모델이 존재하지만 일단 모니터링 시스템 설계 후 시간이 남으면 다시 고려함
