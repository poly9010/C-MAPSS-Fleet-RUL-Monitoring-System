# Database

## 시계열 데이터베이스
시계열DB(TSDB)는 시계열 데이터를 효율적으로 다루기 위해 고안된 데이터베이스이다. 시계열 데이터란 시간의 흐름에 따라 축적되는 데이터를 말한다. 시간의 흐름에 따라 방대한 양의 데이터가 축적되기 떄문에, 관계형DB나 NoSQL로는 시계열 데이터를 처리하는데 한계가 있다.


### 센서 데이터(시계열 데이터)의 특성 <-> TSDB의 특징
-  센서 데이터는 쓰기만 많고 수정 및 삭제는 거의 없다. -> TSDB는 쓰기에 저장 구조가 특화되어 있다.
- 조회는 대부분 시간 단위, 시간별 집계로 한다. -> TSDB는 집계 함수가 내장되어 있다.
- 인접한 값들이 대부분 비슷하다(1.1,1.2,1.3) -> 인접값 간의 차이를 저장함으로써 데이터 크기를 압축할 수 있다.

### RDB로 시계열 데이터를 관리할 시 문제점
- 데이터가 들어올수록 쓰기가 점점 느려진다. -> 행이 들어올 떄마다 인덱스(b-tree)도 갱신해야하기 때문에 메모리가 포화상태가 된다. 즉 하나의 데이터가 들어오게 되면 1. 테이블에 데이터를 저장하고, 2. 인덱스를 갱신한다. -> 쓰기가 많은 센서 데이터에는 적합하지 않다.
- 오래된 데이터를 삭제하기 어렵다. 
- 집계 쿼리가 까다롭다 -> 5분 평균, 이동 평균 같은 집계쿼리를 직접 짜야한다.

## 어떤 DB를 사용할 것인가?
 고려 대상 : InfluxDB, TimescaleDB
 - 사실 본 프로젝트의 데이터는 수만개 수준이기 떄문에 RDB나 influxDB나 속도 면에서는 체감하지 못한다.

### influxDB
influxDB는 시계열 데이터를 효율적으로 다루기 위해 고안된 데이터베이스이다.
시계열 데이터란 시간의 흐름에 따라 축적되는 데이터를 말한다. 관계형DB나 NoSQL로는 시계열 데이터를 처리하는데 한계가 있기 때문에 시계열 데이터를 다루기에 특화된 DB가 만들어졌다.
influxDB는 사용하기 쉬워 보편적인 TSDB로, 다양한 플러그인과 툴을 제공하며 문서정리 또한 잘되어 있다.
