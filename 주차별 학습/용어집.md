# 용어 사전
> 프로젝트를 진행하면서 나오는 용어들에 대해서 정리한 파일입니다. 

### **예지 보전**   
예지 보전은 기계 설비를 실시간으로 모니터링하고 기계에서 나오는 센서 데이터를 분석하여 해당 기계의 고장같은 이상 징후를 사전에 포착하고 예방하기 위한 유지보수 방법이다. 

### **팹**   
팹은 Fabrication(제조)의 줄임말이며, 반도체를 실제로 만드는 공정을 의미한다. 정식으로는 웨이퍼에 회로를 새기는 식각, 노광 등 수백 개의 공정이 이루어지는 초정밀 생산 시설을 뜻한다.

#### **팹의 특징**
- 팹에서는 먼지에 특히 민감하다. 반도체의 회로 선폭이 나노미터 단위기 떄문에, 아주 작은 먼지 하나도 불량의 원인이 된다. 따라서 팹 내부는 클린룸이라는, 공기 중 입자 수를 최대한 낮춘 환경으로 유지된다.

- 웨이퍼는 오염, 진동, 낙하의 위험때문에 사람의 손을 타지 않는다. 따라서 이 웨이퍼를 담는 용기인 Foup을 자동으로 움직이기 위한 시스템이 필요한데, 그게 바로 **AHMS(자동물류시스템)**이다.

### OHT(Overhead Hoist Transport,자동화 이송 장치)
팹에서 웨이퍼를 자동으로 운반하는 기계가 바로 OHT이다. 팹의 천장에 달린 레일로 웨이퍼를 담는 용기인 FOUP를 운반하는 운송장치이다.

### P-value
어떤 사건이 우연히 일어날 확률. 
확인하고싶은 사실 = 대립가설 <br>
확인하고싶은 사실의 반대 = 귀무가설 <br> 
기본적으로 귀무가설이 맞다는 가정하에 통계를 실시함.<br>
p-value < 0.05일 때, 귀무가설을 기각한다 = 대립가설을 채택한다.<br>
> 예를 들어 한 대학교에서 실시한 여론조사 결과에서 표본크기 1000명에서 a후보 지지자가 300명, b후보 지지자가 700명이라고 했을 떄 모집단에서도 "a후보 지지자 < b후보 지지자" 일까? 를 검증하고 싶다.   
 => 대립가설 :  "a후보 지지자 < b후보 지지자"   
 => 귀무가설 : "a후보 지지자와 b후보 지지자 간에는 차이가 없다"   

> p-value = 0.03이라면,   
a후보 지지자와 b후보 지지자는 차이가 없다는 가정 아래에서,   
실제로 1000명을 대상으로 다시 조사했을 때 a후보 지지자가 300명, b후보 지지자가 700명이 나올 확률이 3%라는 뜻이다.
즉, p-value값은 귀무가설을 전제에 뒀을 때 지금같은 데이터가 나올 확률을 의미한다.
