# 센서 데이터의 노이즈 필터링

센서 데이터의 노이즈는  외부 환경 영향, 전기적 간섭, 배선 문제, 접지 불량, 센서 특성 등 다양한 이유로 발생한다. 노이즈는 데이터의 정확도에 영향을 미치기 떄문에 제거하지 않고 분석을 한다면 모델이 잘못된 값을 학습하게 되어 잘못된 결과를 얻을 수 있다. 따라서 노이즈 발생 원인을 이해하고 알맞게 대처하는 것이 중요하다.


### 노이즈 유형
- 백색소음(white noise)
    -  매 시점마다 독립적으로 무작위하게 튀는 노이즈. 아무런 패턴이 존재하지 않는 무작위 값이다. 모든 주파수에서 발생되며(센서 데이터 뿐 아니라 다른 데이터 어디에나 적용된다)
    이동평균, EMA, 저역통과 필터 등으로 걷어내기 쉽다.
    - 백색소음은 **잔차**로 검정함. 따라서 신호를 먼저 모델링한 후, 원본 데이터에서 신호를 뺴서 남은 잔차에 적용하여 검정한다.
    - 판단 기준
        - 평균 = 0(추세가 없는지): 시계열 데이터의 잔차를 구간별로 나누어서 평균을 확인. 예를 들어 3단계로 나뉜다면 1단계 평균, 2단계 평균, 3단계 평균을 구함 -> 모두 비슷하면 추세가 없고, 점점 커지거나 작아지면 추세가 있는것(열화 신호이거나 드리프트가 있는 것)
        - 등분산성 : 구간별로 표준편차를 비교 -> 흔들리는 폭 자체가 시간이 지남에 따라 커지거나 작아지는지 확인 -> 커지거나 작아지면 '완전한' 등분산이 아님
        - 자기상관성이 존재하는지(가장 확실함) : ACF(자기상관함수)그래프를 그려서 lag(시차)가 0이 아닌 모든 지점에서 상관계수가 거의 0근처(신뢰구간 안)에 있는지 확인 -> 만약 lag=1이나 lag=2에서 상관계수가 신뢰구간을 벗어나면 백색잡음x  or Ljung-Box검정 -> 이 데이터에 자기상관이 전혀 없다는 가설을 통계적으로 검정함
    - 백색소음은 노이즈 필터링 방법이 아님. 아직 패턴이 남아있는지, 아니면 진짜 순수 백색잡음 뿐인지를 확인하는 방법임.
- 이상치/스파이크 
    - 평소 패턴과 무관하게 순간적으로 벗어나는 값. 접지 불량, 전기 간섭 등으로 인해 발생하는 노이즈이다. 지속적으로 흔들리지 않고, 순간적으로 크게 벗어낫다가 다시 돌아온다. 
    - 이상치 종류
        - 포인트 이상치 : 다른 정상 데이터와 비교했을 때 범위를 크게 벗어난 경우
        - 문맥 이상치 : 값 자체는 정상 범위이지만, 특정 조건이나 문맥상 비정상인 경우
        - 집단적 이상치 : 개별 값들은 정상 범위지만 여러 값이 특정한 패턴을 이루며 비정상인 경우

    - 판단 기준
        - 시계열 데이터의 경우 단순히 값이 크다고 스파이크가 아님. 이전 시점과의 변화 속도나 차이가 기준이 됨.
        - 1차 차분 임계점 : 현재 측정값과 직전 측정값의 차이가 미리 설정한 임계값을 초과할 시 스파이크로 봄.
        - 이동평균 오차 기준 : 최근 N개 데이터의 이동 평균선 또는 지수 이동평균(EMA)을 구한 뒤, 현재 측정값이 이 평균선으로부터 오차 범위를 크게 벗어났을 때 스파이크로 판단
        - Hampel filter기준 : 실무에서 가장 많이 사용하며, 현재 데이터 주변의 로컬 윈도우 내에서 중앙값을 구하고 그 주변 값들의 중앙값 절대 편차(MAD)를 계산 -> 현재 값이 중앙값으로부터 3xMAD를 넘어가면 스파이크로 판단하고 중앙값으로 대체
        ##### *MAD(중앙값 절대 편차) : |변량 - 중앙값|

- 드리프트
    - 시간이 지나면서 센서의 기준점이 서서히 밀리는 현상. 장비가 진짜로 열화돼서 값이 변하는 것과 센서 자체가 노후화돼서 측정이 틀어지는 것을 잘 구분해야함. 
    - 다만 c-mapss 데이터의 경우 진짜 센서가 아니라 시뮬레이터이기 떄문에 드리프트 현상은 제외함.

- 양자화 노이즈
    - 센서가 값을 기록할 때 주어진 간격 단위로만 표현할 수 있어서 생기는 계단식 오차. 예를 들어 간격이 0.1단위로 값을 기록할 때, 실제로 측정된 값은 0.04만큼 변해도 값은 그대로 기록됨. 데이터를 볼 때 뚝뚝 끊어져있다면 양자화 노이즈일 가능성이 있음.

- 주기성 간섭
    - 전원 주파수 간섭이나 기계적 진동 주기 같은 외부 요인으로 일정한 패턴이 반복적으로 나타나는 노이즈. 



### 이상치 제거 방식
- hampel filter : 현재 시점 주변 데이터들이 중앙값 대비 얼마나 이상한가를 판단
    - 그냥 중앙값으로 필터링하면 이상치가 아닌 모든 점을 다 깎지만 hampel 필터는 이상치만 뽑아내서 중앙값으로 깎음
